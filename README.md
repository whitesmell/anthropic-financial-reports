## 阅读说明

- 本项目是独立整理项目，与 Anthropic 及美国证券交易委员会（SEC）无关联，也不是官方译本。
- 中文内容包含机器翻译及重点人工校订，尚未证明全文逐段校对完成；数字、单位、图表、法律和财务术语尤其需要对照英文原文。
- 英文原始披露及其后续修订为准；文件用于学习研究，不构成投资、法律或财务建议。
- PDF 中的原文图表、商标、客户案例及其他第三方材料可能有独立权利，来源公开不代表可以无条件再分发。发布前需确认所使用素材及译文的权利。
